# Week 02 逻辑回归面试题与参考答案

## 1. 逻辑回归为什么能做二分类？与线性回归共享哪一步？

两者都先计算线性分数 `z = X @ w + b`。逻辑回归用 Sigmoid 将分数转换成正类概率估计 `p = sigmoid(z)`，再通过阈值决定预测类别。有限实数输入下，Sigmoid 的理论值域为 `(0, 1)`。本项目中的线性回归直接输出线性分数并用 MSE 训练，逻辑回归用二元交叉熵（BCE）训练。

## 2. Logit、正类概率和预测类别分别是什么？它们的 shape 是什么？

Logit 是线性分数 `z = X @ w + b`，也等于模型预测的对数几率 `log(p / (1 - p))`。正类概率是 `p = sigmoid(z)`，负类概率为 `1 - p`。预测类别由阈值决定，`p` 大于或等于阈值时返回 1，否则返回 0。

当 `X.shape == (4, 3)`、`w.shape == (3,)` 且 `b` 是标量时，三项输出的 shape 都是 `(4,)`。每个样本各对应一个分数、一个正类概率和一个类别。

## 3. 默认阈值为 0.5 时，为什么可以用 logit ≥ 0 判定正类？

Sigmoid 严格递增，且 `sigmoid(0) = 0.5`，因此在数学上 `z >= 0` 等价于 `sigmoid(z) >= 0.5`。如果把概率阈值改成 0.8，预测概率为 0.7 的样本会判为负类。

## 4. 标签为 1 时，预测概率 0.51 和 0.99 的 BCE 有什么区别？

两者在阈值 0.5 下都判为正类。对应的损失分别是 `-log(0.51) ≈ 0.6733` 和 `-log(0.99) ≈ 0.0101`。BCE 使用模型给真实类别分配的概率，真实类别得到的概率越高，单样本损失越低。

## 5. BCE 的公式是什么？标签为 0 或 1 时如何化简？

令 `p` 为模型预测的正类概率，`y ∈ {0, 1}` 为真实标签。单样本损失为

```text
loss = -(y * log(p) + (1 - y) * log(1 - p))
```

- `y=1` 时，损失为 `-log(p)`。
- `y=0` 时，损失为 `-log(1 - p)`。例如 `p=0.9` 时，真实类别得到的概率是 0.1，对应损失约为 2.3026。

一批样本的 BCE 是各样本损失的平均值。

## 6. 为什么 logit 为 -1000 时直接计算 Sigmoid 可能溢出？如何规避？

直接计算 `1 / (1 + exp(-z))` 时，`z=-1000` 会产生 `exp(1000)`，超出 `float64` 的表示范围。`z >= 0` 时使用原式，`z<0` 时将分子和分母同乘 `exp(z)`，改用 `exp(z) / (1 + exp(z))`。用布尔掩码先筛选再计算，两支传给指数函数的值都不大于 0。

## 7. 概率为 0 或 1 时，为什么需要裁剪？

BCE 同时计算 `log(p)` 和 `log(1 - p)`。概率取边界值时会算到 `log(0)`，得到负无穷，后续还可能因 `0 * (-inf)` 得到 `nan`。本项目用 `np.clip(y_pred, 1e-15, 1 - 1e-15)` 将 `float64` 概率限制在 0 和 1 之间，使对数项保持有限。

## 8. 调整分类阈值会改变 BCE 或预测类别吗？

对同一批标签和预测概率，BCE 保持不变，因为计算公式里没有分类阈值。预测类别可能变化。例如概率为 0.7 时，阈值为 0.5 会判为正类，阈值为 0.8 会判为负类。基于类别计算的 Precision、Recall 和 F1 也可能随之变化。

## 9. Sigmoid 的导数为什么可以用它的输出表示？

令 `p = sigmoid(z) = 1 / (1 + exp(-z))`。由链式法则可得

```text
dp/dz = exp(-z) / (1 + exp(-z))²
      = p * (1 - p)
```

其中 `1 - p = exp(-z) / (1 + exp(-z))`。

## 10. 本项目中 BCE 的 log 以什么为底？

本项目用自然对数 `ln`，与 NumPy 的 `np.log` 一致。对正数 `x`，`d ln(x)/dx = 1 / x`，由链式法则可得 `d ln(1 - p)/dp = -1 / (1 - p)`。阅读其他公式时按资料的约定确认底数。例如以 2 为底时，导数为 `1 / (x * ln(2))`。

## 11. 如何用链式法则推导 fit() 中的梯度？

令 `z = x @ w + b`，`p = sigmoid(z)`，`loss` 为单样本 BCE。对未裁剪的理论损失，当 `0 < p < 1` 时

```text
d loss/dp = -y / p + (1 - y) / (1 - p)
dp/dz     = p * (1 - p)
d loss/dz = (d loss/dp) * (dp/dz) = p - y
```

继续乘上 `dz/dw_j = x_j` 和 `dz/db = 1`，再对样本取平均，就得到 `fit()` 中的两行代码。

```python
dw = (features.T @ (probs - labels)) / len(labels)
db = np.mean(probs - labels)
```
