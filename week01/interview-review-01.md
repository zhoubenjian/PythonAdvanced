# Week 01 线性回归面试题与参考答案

## 1. 线性回归中，w 和 b 分别表示什么？

在 `y_pred = X @ w + b` 中，`w` 是特征权重向量，每个特征对应一个权重，所有样本共享这组权重。`b` 是截距，即所有特征都为 0 时的预测值。

## 2. dw 和 db 是什么？参数的实际变化量是多少？

`dw` 是损失对权重向量的梯度，`db` 是损失对截距的偏导数。一次更新中，权重和截距的变化量分别为 `-learning_rate * dw` 和 `-learning_rate * db`。

## 3. 为什么沿负梯度更新参数？

在梯度非零时，梯度指向损失在当前位置上升最快的方向。沿负梯度走足够小的一步，损失就会下降。

## 4. 学习率过大或过小会怎样？

学习率过小时，参数每步更新幅度小，给定训练轮数内可能仍远离最优点。学习率过大时，更新可能跨过最优点，导致损失震荡或发散，甚至产生 `inf` 或 `nan`。

## 5. 给定 X 的 shape 为 (4, 1)，各中间结果的维度是什么？

当 `w.shape == (1,)`、`y.shape == (4,)` 且截距是标量时，各结果的维度如下。

```text
(X @ w).shape       = (4,)
error.shape         = (4,)
X.T.shape           = (1, 4)
(X.T @ error).shape = (1,)
dw.shape            = (1,)
```

其中 `error = y_pred - y`。

## 6. 为什么 dw 的 shape 与 w 相同？

每个特征的权重都有一个对应的偏导数，梯度按相同顺序排列，方便逐元素更新权重。例如 4 个样本、3 个特征时，`X.shape == (4, 3)`，`w` 和 `dw` 的 shape 都是 `(3,)`，而 `X @ w` 的 shape 是 `(4,)`。

## 7. SSE、MSE、RMSE 和 MAE 分别是什么？

令 `error = y_pred - y_true`。以 NumPy 写法表示：

```text
SSE  = np.sum(error ** 2)
MSE  = np.mean(error ** 2)
RMSE = np.sqrt(MSE)
MAE  = np.mean(np.abs(error))
```

SSE 是误差平方和，MSE 是误差平方的平均值，RMSE 是均方根误差，MAE 是平均绝对误差。

## 8. 为什么 MSE 适合作为线性回归的损失函数？

MSE 对线性模型的权重和截距是可导的凸函数，便于用梯度下降优化。在误差独立、同方差且服从零均值高斯分布的假设下，最小化 MSE 与求回归参数的最大似然估计等价。

## 9. MSE 为什么对异常值敏感？如何减小大误差样本的影响？

平方会放大大误差。例如误差从 `2` 增加到 `10`，平方误差从 `4` 增加到 `100`。可以考虑 MAE，或采用 Huber 损失，对小误差使用二次惩罚、对大误差使用线性惩罚。

## 10. 损失函数与评价指标有什么区别？两者必须相同吗？

损失函数用于优化模型参数，评价指标用于衡量模型在验证、测试或实际业务中的表现。两者可以相同，也可以按目标分别选择。例如分类模型可以用交叉熵训练，用 Recall 或 F1 评价。

## 11. 为什么损失曲线使用对数纵轴？

对数刻度让相同倍数的变化占据相同距离。`1 → 0.1` 和 `0.01 → 0.001` 都下降了 10 倍，纵向距离相同。这有助于同时观察跨多个数量级的正损失值。

## 12. 为什么学习率 0.05 更早达标，而 0.1 的末次记录损失更低？

在本实验中，`0.05` 和 `0.1` 分别在第 12 和第 13 条记录首次低于 `0.01`。第 100 条记录的损失分别约为 `6.92e-4` 和 `3.34e-5`。首次达标的速度和固定训练预算下的损失是两种比较标准。每条记录对应当轮参数更新前的损失。

## 13. 特征放大 10 倍后，为什么原学习率可能导致发散？

保持 `y` 不变且参数从零初始化时，初始误差仍是 `-y`。根据 `dw = (2 / n_samples) * (X.T @ error)`，本实验中的首次权重梯度从 `-35` 变为 `-350`。使用 `lr = 0.1` 更新后，权重为 `35`。此时第一个样本的特征已变为 `10`，仅权重项就达到 `350`，目标值是 `3`。特征尺度改变了损失对权重的曲率，因此可用的学习率范围也可能改变。

## 14. 特征做线性变换后，怎样调整权重和截距以保持预测不变？

原模型为 `y = w * x + b`，特征变换为 `x_new = a * x + c`，其中 `a != 0`。将 `x = (x_new - c) / a` 代回原模型，得到 `w_new = w / a` 和 `b_new = b - w * c / a`。

- 原模型为 `y = 2 * x + 1`，若 `x_new = 10 * x`，新权重为 `0.2`，截距为 `1`。
- 同一个模型中，若 `x_new = 10 * x + 5`，新权重为 `0.2`，截距为 `0`。
- 原模型为 `y = 3 * x + 2`，若 `x_new = 2 * x + 4`，新权重为 `1.5`，截距为 `-4`。用 `x = 0` 验算，此时 `x_new = 4`，两个模型都预测 `2`。

## 15. 标准化之后，线性模型的权重和截距怎么变？

若 `z = (x - μ) / σ` 且 `σ > 0`，将 `x = σ * z + μ` 代入原模型，得到 `w_z = w * σ` 和 `b_z = b + w * μ`。当 `z = 0` 时，原特征等于均值 `μ`，因此新截距就是原模型在这个点的预测值。
