## 第 1 题：参数与梯度下降

### 题目

已知：

```python
y_pred = X @ w + b
loss = np.mean((y_pred - y) ** 2)
```

回答：

1. `w` 和 `b` 分别表示什么？
2. `dw` 和 `db` 是什么？它们是否等于参数的实际变化量？
3. 为什么使用负梯度更新参数？
4. 学习率过大或过小分别会怎样？

### 参考答案

- `w` 是特征权重；多特征情况下它是向量。`b` 是截距。
- `dw = ∂Loss/∂w`，`db = ∂Loss/∂b`，二者是损失对参数的梯度，不是参数变化量。
- 真正的变化量是 `-learning_rate * dw` 和 `-learning_rate * db`。
- 梯度指向当前位置损失上升最快的方向，因此沿负梯度方向更新，可以让损失局部下降。
- 学习率过大可能震荡或发散，甚至产生 `inf`、`nan`；过小则收敛缓慢，有限轮次内可能仍远离最优点。

### 推荐面试表达

> `dw` 和 `db` 是 MSE 对参数的偏导数。梯度表示损失上升最快的方向，所以用负梯度乘以学习率作为参数变化量。学习率控制每次更新的步长，过大会震荡或发散，过小会使收敛速度过慢。

## 第 2 题：矩阵维度

### 题目

假设：

```python
X.shape == (4, 1)
w.shape == (1,)
y.shape == (4,)
```

回答 `X @ w`、`error`、`X.T`、`X.T @ error` 的 shape，并解释为什么 `dw` 和 `w` 的 shape 必须相同。

### 参考答案

```text
X.shape              = (4, 1)
w.shape              = (1,)
(X @ w).shape        = (4,)
error.shape          = (4,)
X.T.shape            = (1, 4)
(X.T @ error).shape  = (1,)
dw.shape             = (1,)
```

每个特征对应一个共享权重，而不是每个样本拥有一组独立权重。若有 4 个样本、3 个特征，则 `X.shape == (4, 3)`，但 `w.shape == (3,)`。参数更新是逐元素进行的，因此 `dw.shape` 必须与 `w.shape` 相同。

## 第 3 题：MSE 与评价指标

### 题目

1. MSE 的公式是什么？
2. 为什么 MSE 可以作为线性回归的损失函数？
3. MSE 对异常值敏感吗？
4. 如何减小异常值的影响？
5. 损失函数与评价指标有什么区别？

### 参考答案

MSE 的公式：

```text
MSE = (1 / n) * Σ(y_pred_i - y_true_i)²
```

对应代码：

```python
np.mean((y_pred - y_true) ** 2)
```

- 只有平方和的是 SSE；平方和除以样本数才是 MSE。
- MSE 连续且可导，便于梯度优化；在线性回归中目标函数是凸的。
- 在误差服从均值为 0 的高斯分布这一假设下，最小化 MSE 等价于最大似然估计。
- MSE 对异常值敏感，因为误差平方会显著放大大误差。
- 可使用 MAE 降低异常值影响；也可考虑兼顾平滑性与鲁棒性的 Huber Loss。
- 损失函数用于训练阶段优化参数，通常需要容易优化；评价指标用于验证、测试和业务判断，不一定可导，也不一定参与训练。
- 二者可以相同，但不必须相同。例如分类模型可用交叉熵训练，用 Accuracy、Recall 或 F1 评价。

### 推荐面试表达

> MSE 是预测误差平方的平均值。它连续、可导，在线性回归中还是凸目标，因此适合梯度优化；但平方项会放大异常值。如果数据异常值较多，可以考虑 MAE 或 Huber Loss。损失函数用于训练参数，评价指标用于衡量模型是否符合技术或业务目标，二者不要求相同。
