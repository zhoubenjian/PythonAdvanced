# AI 转型面试补课路线

目标岗位：AI 应用工程师 / 机器学习工程师（偏后端与平台）。

本清单与每周项目并行推进。建议每周投入 3-5 小时，不追求一次学完；每个知识点依次标记为：

- `[ ]` 尚未学习
- `[~]` 能描述概念，但不能结合代码或案例
- `[x]` 能解释原理、适用场景、失败情况，并能联系项目

## Python

- [ ] `list`、`tuple`、`set`、`dict` 的特点与常见操作复杂度
- [ ] 可变对象、不可变对象与函数传参
- [ ] 浅拷贝与深拷贝
- [ ] 迭代器与生成器
- [ ] 装饰器与上下文管理器
- [ ] GIL、线程、进程、协程的区别
- [ ] 类型标注、异常处理与 pytest
- [ ] NumPy 的 shape、广播与向量化

## 机器学习

- [ ] 监督学习、无监督学习、回归与分类
- [ ] 损失函数与评价指标
- [ ] 梯度下降与学习率
- [ ] 过拟合、欠拟合、偏差与方差
- [ ] L1、L2 正则化
- [ ] 训练集、验证集、测试集与交叉验证
- [ ] 数据泄漏与数据分布变化
- [ ] 特征标准化与类别不平衡
- [ ] Accuracy、Precision、Recall、F1、ROC-AUC
- [ ] 线性模型、决策树、随机森林、GBDT、XGBoost

## 数学

- [ ] 向量、矩阵乘法与维度推导
- [ ] 导数、偏导数、梯度与链式法则
- [ ] 最小二乘法
- [ ] 均值、方差、协方差
- [ ] 条件概率与贝叶斯公式
- [ ] 常见概率分布
- [ ] 最大似然估计
- [ ] 信息熵与交叉熵
- [ ] 特征值与特征向量

## SQL 与算法

- [ ] JOIN、GROUP BY、子查询与窗口函数
- [ ] 索引的基本原理与失效场景
- [ ] 数组、字符串与哈希表
- [ ] 栈、队列与链表
- [ ] 二分查找、双指针与滑动窗口
- [ ] BFS 与 DFS
- [ ] 基础动态规划
- [ ] 时间复杂度与空间复杂度

## AI 工程与系统设计

- [ ] 在线推理与批量推理
- [ ] 同步接口与异步任务
- [ ] 缓存、限流、超时与重试
- [ ] 模型版本、灰度发布与回滚
- [ ] 日志、指标、链路追踪与告警
- [ ] 延迟、吞吐量、可用性与成本权衡
- [ ] 数据漂移与模型效果监控

## LLM 应用

- [ ] token 与上下文窗口
- [ ] embedding 与相似度
- [ ] Transformer 与注意力机制
- [ ] Prompt 的基本结构与边界
- [ ] RAG：解析、切分、检索、重排、生成
- [ ] 幻觉、拒答与引用
- [ ] RAG 离线评估与线上指标
- [ ] 提示注入、数据权限与隐私
- [ ] 延迟与调用成本

## 面试回答模板

学习一个算法或组件后，应能回答：

1. 它解决什么问题？
2. 核心原理是什么？
3. 有哪些重要参数？
4. 如何评价效果？
5. 什么情况下会失败？
6. 在当前项目中如何使用或验证？
